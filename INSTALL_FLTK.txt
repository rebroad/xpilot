These are the instructions on how to build fltk, The XPilot version.
This is just a convienence.  The full monty can be found at

        http://fltk.sourceforge.net/

That said, we have run into problems with incompatible versions;
xpilot5 is currently built with fltk 1.1.0b1
I'm sure fltk 2.0 (in development as of this writing) will not
be compatible at all, since the fltk developers warn of this.

So, first you need to fetch fltk for XPilot.

*Warning* Installing this will overwrite any existing fltk installation
that you have.

================================================================================
Pick a directory to build in.
$ mkdir ~/xpilot
$ cd ~/xpilot

================================================================================
Pick a distribution.

1) The CVS way:

   $ cvs -d :pserver:anonymous@cvs.buckosoft.com:/Projects/xpilot5 login
   [press return for a blank password]
   $ cvs -d :pserver:anonymous@cvs.buckosoft.com:/Projects/xpilot5 co fltk
   (This might be a good time to fetch the xpilot5 source too)
   cvs -d :pserver:anonymous@cvs.buckosoft.com:/Projects/xpilot5 co xpilot5

2) The HTTP way:
   $ lynx -raw -source http://www.buckosoft.com/pub/xpilot/fltk-20010801.tar.bz2 >fltk-20010801.tar.bz2
   $ tar -xvyf fltk-20010801.tar.bz2


================================================================================
UNIX:
$ cd ~/xpilot/fltk
$ ./configure
$ make
$ su
$ make install

If you don't have have root privileges, or you don't want to overwrite your
existing fltk installation, you can build xpilot pointing to this "local" copy of
fltk.  See Local.config for details.

================================================================================
WINDOWS:
In Visual C++ open ~/xpilot/fltk/visualc/fltk.lib.dsw
Build both the Debug and Release versions.

(While it's building, you can add these.)
Tell Visual C++ where to find your fltk distribution.
Menu: Tools / Options / Directories
Include files:  Add the full path to your fltk directory. ~/xpilot/fltk
Library files: Add the full path to the lib subdirectory of your fltk.  ~/xpilot/fltk/lib

================================================================================
That's it!
xpilot5 should now build
